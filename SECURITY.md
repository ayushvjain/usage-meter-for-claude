# Security policy

The widget keeps a signed-in claude.ai session on the user's computer, so security issues matter.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's private reporting instead: the repository's **Security** tab > **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply within a week.

## Scope

In scope: anything that could expose a user's claude.ai session, send data anywhere other than claude.ai, or let a web page or theme file run code with the app's privileges.

Out of scope: claude.ai itself. Report those to Anthropic.
